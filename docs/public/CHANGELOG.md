# Changelog

## 1.26.0 (62) · 2026-09-15

- 新增可安装的 Windows x64 命令行包，提供版本查询并复用现有受保护合入与进度引擎。
- GitHub 标签发布同时构建并上传 macOS、Windows 安装包、校验文件和安装命令；本次保持版本号与构建号不变。
- 发布流程拆分为试用构建、精确包确认和受控下发；未试用、重新构建或改版本后均不能更新交付目录。
- Dev 与 Release 工作副本可分别手动设置；合入端点名称从路径的最后一级目录派生，内部源/目标角色保持稳定。
- 合入工具的导航项、窗口标题、方向提示与目标状态随配置动态显示。

## 1.25.0 (60) · 2026-09-15

- 统一最终交付目录，新增 macOS shell 与 Windows PowerShell 安装命令。
- 安装器校验平台、架构、SHA-256 和包内版本，并采用用户级默认目录及失败回滚。
- Windows GUI 产物缺失时明确停止，禁止把共享验证引擎当作桌面软件安装。
- 记录 uv、rustup 与 ripgrep 的安装/发行设计依据。

## 1.24.0 (59) · 2026-09-15

- 建立共享合入引擎的 macOS/Windows 构建基础，新增跨平台 JSON 配置与互斥文件锁。
- macOS 包可使用受限的独立运行引擎，不再要求把开发机 Python 目录直接复制进应用。
- 移除安装包中打入真实开发报告的逻辑；可选的内部导出集成缺失时改为明确不可用，不泄漏或猜测依赖。
- 新增公开文件边界检查、秘密扫描工作流和跨平台 CI 验证。
- 测试作者改为虚构账号；报告、工作簿、日志、内部设计资料和本机设置默认不进入 Git。

Windows 的 SwiftUI/AppKit 图形界面不在 Windows 包中；Windows 当前交付可安装的命令行版本。
